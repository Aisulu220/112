# Medical Health – 15 feature folders

This archive contains 15 independent React Native + TypeScript feature folders.
Each folder contains:
- `index.tsx` – a starter screen component
- `styles.ts` – styles for that screen
- `types.ts` – TypeScript types

## Installation
1. Extract the ZIP.
2. Copy the 15 folders into your existing `src/features/` folder.
3. Keep your existing `src/components`, `src/data`, `src/screens`, `src/styles`, and `src/types` folders.
4. These screens use only `react` and `react-native`; no extra package is required.

## Important
These are clean starter screens, not a replacement for your existing screens. They are not yet registered in `App.tsx` navigation. To connect them safely, add imports and navigation routes in your existing navigator. Share your current `App.tsx` if you want the exact integration code.
